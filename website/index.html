PRIVATE HTTPS CONNECTION

把手机连到
正在运行的电脑。

Serve HTTPS 只把电脑上的 Agent Bridge 提供给同一 Tailscale 私有网络内的设备。以下命令在电脑上运行，手机不用输入命令。

开始前① 电脑打开 Agent Bridge 和 Codex② 电脑、手机或 iPad 登录同一个 Tailscale 网络③ 先在电脑浏览器打开 http://127.0.0.1:4571/api/health，确认返回 "ok":true

Windows 电脑

打开 PowerShell。若已给 Tailscale 配过其他 Serve 路由，先看第一条命令的结果，避免覆盖原有 443 根路由。

1 · 查看已有路由
& "$env:ProgramFiles\Tailscale\tailscale.exe" serve status
2 · 开启后台 HTTPS 转发
& "$env:ProgramFiles\Tailscale\tailscale.exe" serve --bg --https=443 http://127.0.0.1:4571
3 · 再次检查
& "$env:ProgramFiles\Tailscale\tailscale.exe" serve status

如果提示找不到程序，请确认 Tailscale 已安装；若装在别处，将命令中的程序路径改成实际路径。

Mac 电脑

打开“终端”。下面是 Tailscale 官方 Mac App 的常见位置；如果使用其他安装方式，请换成实际的 CLI 路径。

1 · 查看已有路由
TAILSCALE_BE_CLI=1 /Applications/Tailscale.app/Contents/MacOS/Tailscale serve status
2 · 开启后台 HTTPS 转发
TAILSCALE_BE_CLI=1 /Applications/Tailscale.app/Contents/MacOS/Tailscale serve --bg --https=443 http://127.0.0.1:4571
3 · 再次检查
TAILSCALE_BE_CLI=1 /Applications/Tailscale.app/Contents/MacOS/Tailscale serve status

仅在运行 Agent Bridge 的那台 Mac 上执行；Windows 和 Mac 各有自己的 HTTPS 地址。

看到什么算成功？

命令显示 https://你的电脑名.…ts.net，且 serve status 显示根路径 / 转发到 http://127.0.0.1:4571。如果提示 Serve is not enabled on your tailnet，先打开命令给出的 Tailscale 授权链接，启用 HTTPS／Serve，再重新执行第 2 步。接着在已连接 Tailscale 的手机浏览器打开这个 HTTPS 根地址，能看到配对页面后，把同一地址填进 Android 应用或在 iPad Safari 使用。

这里使用的是仅限私有网络的 Serve，无需开启公开访问的 Funnel。已有 443 路由指向别的服务时，请先确认用途，不要直接覆盖，也不要运行 tailscale serve reset。

HELP & TROUBLESHOOTING

遇到问题，
从这里排查。

按安装、连接、配对、聊天和通知整理了常见情况。先看电脑窗口里的服务状态，再看手机上的提示。

Tailscale 显示“Serve is not enabled”怎么办？
打开命令输出中的 Tailscale 授权链接，在网页上启用 HTTPS／Serve。回到电脑后重新执行对应系统的开启命令，再运行 serve status 核对。不要开启 Funnel。
终端提示找不到 tailscale 命令怎么办？
先确认 Tailscale 已安装并已登录。Windows 可使用上方 PowerShell 示例中的完整 tailscale.exe 路径；Mac 可使用上方带 TAILSCALE_BE_CLI=1 的完整路径。若装在其他目录，替换成实际程序位置。
Serve 的 443 端口已有别的服务怎么办？
先用 serve status 确认现有路由属于什么服务。不要直接执行本页开启命令覆盖 443 根路径，也不要运行 serve reset。需要保留原服务时，请先为 Agent Bridge 规划独立的 HTTPS 路由或端口，并在移动端使用相应地址。
打开 HTTPS 地址却看到别的网站？
通常是 Serve 仍把根路径转发到另一个本机服务，或者复制了另一台电脑的地址。对照 serve status：此设备的根路径 / 应转发到 http://127.0.0.1:4571；确认前不要清空已有路由。
电脑有 HTTPS 地址，但手机提示 unable to resolve host？
确认手机上的 Tailscale 已连接，并与电脑登录同一个私有网络；从电脑 serve status 复制完整的 https://…ts.net 根地址，检查拼写，不要复制旧电脑的地址。先在手机浏览器打开这个地址；浏览器也无法解析时，先排查 Tailscale 连接和 DNS。
手机一直 read timeout 或页面打不开？
先在电脑浏览器打开 http://127.0.0.1:4571/api/health。若不返回 "ok":true，先重开 Agent Bridge；若本机正常，再看 serve status 是否转发到 4571，以及手机 Tailscale 是否在线。网络切换、休眠和系统后台限制也会导致超时。
手机能打开网页，却提示桌面端没有打开？
这表示手机已接触到网页服务，但电脑端的 Codex 连接可能尚未建立。打开电脑上的 Codex 和目标聊天，再看 Agent Bridge 窗口状态；确认手机填写的是当前运行 Agent Bridge 的这台电脑的地址。
配对码不出现、过期或手机重新配不上怎么办？
在电脑窗口点击“添加设备”生成新码；配对码有效期短，请及时在手机输入。若要撤销所有已配对设备，再用“重新配对”。已经成功的旧设备不需要为了添加新手机而全部重配。
Windows 双击安装包或程序没有反应？
确认下载的是 Windows 安装包，安装后从开始菜单打开 Agent Bridge；检查任务栏通知区域是否已有窗口或后台实例。若窗口依然不出现，查看系统是否拦截运行及应用安装位置，并先退出旧实例再重试。不要用 Mac 的 DMG 在 Windows 上安装。
为什么看不到 Codex 聊天列表？
确认是 Codex 桌面应用、已登录并打开目标聊天。先看电脑窗口是否显示具体聊天已连接。Mac 预览版若没有可用的聊天列表端点，会读取本机最近聊天索引；索引没有内容或 Codex 主通道不可用时仍可能无法选择。
能看到聊天，但发消息或审批没有反应？
先确认电脑上的 Codex 仍在运行、手机选中正确的聊天，并检查 Agent Bridge 窗口日志。审批要在请求有效期内处理；过期或已经由另一设备处理的请求不能再次批准。发消息后若提示失败，不要连续重发同一指令，先核对电脑聊天里是否已收到。
连接状态是绿色，为什么还收不到聊天？
绿色状态只表示当前连接检查通过，不等于 Codex 正在生成回复，也不保证系统通知已显示。确认移动端选中了正确聊天、电脑 Codex 主通道仍连接；有结果时先在应用内查看，再检查系统通知权限。
Mac 安装包提示无法验证或没有权限？
当前 DMG 是 Apple 芯片预览包，使用本地测试签名，未经苹果公证。把 App 从 DMG 拖入“应用程序”，从那里启动；若系统拦截，在“系统设置 → 隐私与安全性”审核该 App 后选择打开。Intel Mac 尚未完成实际接入验收。
iPad 为什么没有“添加到主屏幕”或通知？
用 Safari 打开电脑的 HTTPS 地址，在分享菜单中选择“添加到主屏幕”，再从主屏幕图标启动；介绍网站本身不是控制页面。网页通知要求 iOS／iPadOS 16.4+，并需在网页 App 和系统中允许通知。浏览器标签页里的权限状态与主屏幕网页 App 可能不同。
Android 在前台有消息，后台却没有通知？
检查 Agent Bridge 的通知权限、后台连接状态，以及手机对 Agent Bridge 和 Tailscale 的省电与后台运行限制。小米等机型还需检查应用后台启动和通知类别。先确认通知栏里是否有“后台连接”通知；没有时优先恢复后台服务与网络，再做测试事件。
为什么有时慢、有时通知会漏？
任务完成到推送显示之间还经过电脑服务、Tailscale、手机网络和系统通知调度。电脑休眠、手机断网或省电策略可能造成延迟。电脑和手机不必同一 Wi-Fi，但必须保持在线；审批以应用内待办状态为准，重要请求不要只依赖横幅。
与 OpenAI、Tailscale 有官方合作吗？
Agent Bridge 是独立开发的配套工具，与 OpenAI、Tailscale 无官方合作或背书关系。页面提及 Codex 和 Tailscale，是为了说明使用方式与连接依赖。现有连接方式可能需要随 Codex 桌面版本更新而适配。
需要服务器，或者另外安装 Node.js 吗？
不需要另租服务器。Windows 与 Mac 安装包均内置 Node.js，日常启动只需打开 Agent Bridge。电脑上的 Codex 和 Agent Bridge 需要保持运行；首次安装仍需配置 Tailscale HTTPS。Codex hooks 是可选接入，安装前请先审核其内容。
手机和电脑必须连同一个 Wi-Fi 吗？
不必。两端需要登录同一 Tailscale 私有网络并保持在线，可以跨 Wi-Fi 和移动网络连接。实际连接速度和通知到达时间受网络质量、后台运行和系统电池管理影响。
后台通知一定能收到吗？
通知需要电脑在线、移动端网络畅通和系统权限开启。Android 需要开启后台连接，并允许 Agent Bridge 与 Tailscale 在后台运行；iPad / iPhone 需要添加到主屏幕并开启网页通知。系统省电策略或断网可能造成延迟，当前版本不能保证每一条提醒即时送达。
手机和 iPad 能同时使用吗？
可以。电脑端选择“添加设备”为另一台设备生成配对码，每台设备可独立选择聊天。同一个请求只能处理一次。“重新配对”会撤销全部旧设备。Mac 预览版目前仅确认监测已选聊天，其他聊天的后台待办提醒仍待验收。
