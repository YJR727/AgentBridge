# Agent Bridge 电脑端 0.2.5

推荐入口：dist/AgentBridge-Setup-0.2.5.exe；便携入口 dist/AgentBridge-0.2.5.exe。双击安装到当前用户的 %LOCALAPPDATA%\Programs\Agent Bridge，创建桌面与开始菜单快捷方式，可在 Windows 设置中卸载。无需管理员权限。安装包不包含实际配对资料或密钥。

Windows 10 1809 及以上、x64、.NET Framework 4.8。窗口由 C# + WPF 直接运行，不再启动 PowerShell。界面使用项目标志、青绿色按钮、独立状态与配对卡片；PerMonitorV2 声明、布局取整与滚动布局支持高分辨率和较小屏幕。

## 使用

1. 首次替换旧 0.1.x 版本，请先从旧版系统托盘退出，再运行安装包。以后从桌面 Agent Bridge 图标启动。
2. 自动启动内置 Node 服务，显示服务状态、当前聊天和配对状态。启动时检测 Tailscale，之后每十秒刷新，也可点击“重新检测”。未安装时每次启动自动打开一次官方 Windows 安装页，窗口保留“去安装”按钮；已安装时提供“打开 Tailscale”。区分未开启、未登录、等待授权、未连接和电脑端已连接；无法读取状态时提示待确认，不冒充未安装。检测不自动登录、安装或修改网络设置。
3. 第一台设备照常输入配对码；之后点击“添加设备”，在另一台输入五分钟内有效的一次性新码，原设备、订阅及所选聊天保留。新版 APK 0.4.2 与 iPad 网页各自选择聊天，审批仍只能处理一次。“重新配对”会先说明撤销所有旧设备权限及待处理审批，确认后生成新码。正常重启不撤销设备权限，但未使用的添加码会作废。
4. 复制地址、打开网页、通知测试与日志都在窗口中。测试只创建假审批，不执行电脑命令；日志默认收起。
5. 关闭窗口隐藏到系统托盘；再次双击程序或托盘图标唤回。退出程序仅停止本窗口启动的服务，已复用的外部服务不会被停止。
6. 后续更新与卸载会请求新控制台正常退出，保留配对资料与日志。

各设备选中的 Codex 聊天回复完成后，自动发送一次完成通知，摘要为纯文本，点击可读取保存的完整回复。所有运行且已加载的本机聊天的审批/提问进入全局待办，来源明确，处理时不切换当前目标。请覆盖安装 APK 0.4.2；iPad 完全关闭再从主屏幕图标打开获取网页 0.4.2，保有通知订阅。首次连接、切换聊天、重新连接时的已有回复不补发，取消和失败不冒充完成；完成通知有效期五分钟。最终正文显示实际耗时/当地完成时刻，缺字段显示时间不可用。红绿圆点确认的是当前聊天连接，十秒未确认转红。默认完成提醒启用，可在 notify.replyCompleted 配置项设为 false。

地址可自动读取已连接的 Tailscale，也可手动填写完整 HTTPS 根地址；已有地址不会被覆盖。状态检测失败不会阻止本地服务启动。“电脑端已连接”不代表手机 VPN 在线或通知已送达。新电脑安装 Tailscale 后仍需登录并配置 Serve HTTPS；本次检测不会修改已有转发规则。

## 数据与兼容

0.2.3 修复带大量图片或附件的聊天无法连接的问题：桌面消息容量从 32 MiB 提高到 128 MiB，每条消息只分配一次缓冲区并分段读取。超过上限时显示明确原因，不再误报桌面未开启。未加载的聊天仍需先在电脑 Codex 中打开；Android 与 iPad 无需更新。

设置、日志、运行缓存位于 %LOCALAPPDATA%\AgentBridge。优先沿用已记录的资料目录，其次沿用原项目 data，保留手机凭证、订阅、VAPID 配置与 Codex 记录。卸载不删除这些资料。

设备共享现有控制凭证，添加设备保留初次配对时间；本版不提供单独移除设备。随机设备标识只用于区分选择，并非凭证。旧客户端没有标识时保留共享选择入口。只有持有电脑 hook 凭证的控制窗能发放添加码，手机凭证不能生成或读取配对码。服务启动会关闭临时配对入口。新版检测旧服务是否支持独立聊天，若旧服务仍在运行会提示先退出，避免默默复用缺少功能的旧服务。

当前已信任的 Codex hook 仍引用原项目目录中的 `hook.mjs` 和本机 Node.js 路径，所以暂时保留这两个位置。本次安装不搬迁 hook、不改变信任、全局 Codex 配置或 Tailscale 路由。电脑 Codex 与两端 Tailscale 仍需运行。其他电脑需独立配置。

便携入口 dist/AgentBridge.exe 内嵌 Node、服务、网页与官方 Node 许可证，首次运行解压到用户缓存。删除了旧 desktop/controller.ps1，无新增运行 npm 依赖。

## 构建与验证

- `desktop/build.ps1 -NodePath <Node.js 可执行文件路径>`：Windows 自带 C# 编译器构建 WPF EXE；XAML 是嵌入资源。
- desktop/build-installer.ps1 -Compiler <ISCC.exe路径>：Inno Setup 7.1 编译安装包；编译器仅为构建工具。遵循其许可证，目前本项目为个人非商业用途。
- desktop/verify.ps1 -Executable <EXE路径>：独立资料目录、空闲端口验证后台启动、配对保留、假审批回传、撤销、拒绝错误凭证、复用、退出与断管清理。检查日志折叠、关闭留托盘和重复打开唤回，保存四档 DPI 渲染图。这些渲染检查不等同于在不同物理显示器间切换的验收。
- desktop/verify-installer.ps1：独立目录实际安装交付包，验证安装后的 EXE、运行中升级与卸载，核对资料哈希未变。已有正式安装时拒绝运行；已有快捷方式时备份并使用不创建图标的安装方式，检查原文件未变，失败时恢复备份，否则同时验证新快捷方式。安装器同时启用 AllowNoIcons 和各图标的 WizardNoIcons 检查。
- node tools/run-tests.mjs：现有后台回归，Windows 命名管道检查需要允许本地通信。

--check 不启动服务或更改配对。--self-test 必须设置隔离 AGENT_BRIDGE_DESKTOP_HOME、AGENT_BRIDGE_DATA 与 AGENT_BRIDGE_PORT，不可用于真实手机资料。--quit 仅通知同一控制台资料下的窗口正常退出，用于更新与卸载。

## iPad 推送修复记录

本机 vapid.subject 原为 mailto:agent-bridge@localhost，苹果返回 403 BadJwtToken。保持密钥和订阅，仅改为本机真实 HTTPS 地址后返回 201；配置已保存。重启后常规审批也返回 201，并收到 approve，用户已确认可用。通用默认配置没有写入本机地址，其他机器需填写自己的真实 HTTPS 联系地址或邮箱。
