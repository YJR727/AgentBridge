# Agent Bridge 安卓 APK

这是可侧载安装的原生安卓应用，不需要浏览器，不依赖 Google Play/Firebase。兼容目标为 Android 8.0（API 26）及以上，包含通用 DEX，无 CPU 架构专属原生库。APK 编译/签名验证不等于各品牌真机验收。

## 安装和使用

1. 电脑保留并运行更新后的 Node 服务。在源码项目目录双击 `start.cmd`；发布包解压后双击 `service\start.cmd`。不要运行两个实例。
2. 电脑与手机安装 Tailscale 并登录同一 tailnet。电脑启用 Tailscale Serve HTTPS，查看实际地址：`tailscale serve --bg http://127.0.0.1:4571`。已有 Serve 路由时先检查，不覆盖其他服务，不使用 Funnel。
3. 将 `agent-bridge.apk` 传到手机，允许文件管理器安装来自此来源的应用，然后安装“Agent Bridge 手机桥”。不需要安装开发工具或创建开发者账号。
4. 打开手机桥，填写电脑的 `https://…ts.net` 地址和五分钟配对码，在“设置”页点“确认配对”。电脑若已保存旧配对，在 start.cmd 打开的“电脑配对”控制窗点击“重新配对，生成新码”，再填新码；按钮会撤销旧手机权限及待处理审批。凭证仅保存在应用私有目录，禁止系统备份；APK 不含电脑地址、真实令牌、订阅或私钥。
5. 在“聊天”页点顶部聊天标题，选中已在电脑打开的聊天；在底部输入指令发送。新完整回复自动刷新，可点“复制”获取原文。“待办”页查看申请，打开详情后回答选项/文字问题或审批。在“设置”页允许通知并开启“后台连接”；需要测试时点“发送测试审批”。系统通知保留批准/拒绝入口。
6. 在“通知与电池设置”中允许手机桥和 Tailscale 后台运行，并按厂商要求允许自启动、锁屏通知。手机重启后手动重新开启后台连接。

这个 APK 使用可见的前台连接服务，经 HTTPS 每五秒拉取一次事件，无云推送账户。后台连接会占用网络和 CPU 唤醒、增加耗电；常驻通知有“停止连接”按钮，应用内也可停止。Android Doze 与厂商电池管理可能延迟或终止网络，需真机测试；不能承诺所有手机锁屏必达。Google Play 不参与通知路径，但手机与电脑的 Tailscale、电脑服务仍须在线。

## 当前能力与验收

v0.4.2 延续“聊天 / 待办 / 设置”三页、固定底部输入框和独立问题与审批详情页，修正底栏的大按钮阴影：改为平面导航，当前页图标使用小型浅绿标记，输入框与发送按钮对齐；导航支持随系统字体增大高度。回复支持标题、粗体、列表、引用、行内代码、代码块及 HTTPS/HTTP 链接；未支持的格式保留文字，不引入 Markdown 运行库。复制完整回复保留原文，复制代码保留原始符号和空行。

沿用 v0.3.0 的已有聊天选择、发指令、完整回复、选项/文字/多问题回答和通知协议。先在电脑打开聊天，再在手机选择它；测试审批仍是假事件。新底栏效果、长文、键盘、横屏、大字号和通知跳转仍需真机确认。可用原签名直接覆盖安装，保留配对。配套包的电脑服务为 v0.4.0，包含同样三页网页界面及桌面问题推送；旧服务使用新增网页能力需重启，但 APK 只更新了底栏。

- 分别测试批准和拒绝，查看电脑与手机中的对应事件，不串事件。
- 连发两条测试审批，应收到两条独立通知。
- 不点击等待默认 90 秒，过期按钮回传应失败；不能显示“已批准”。
- 断开手机网络、关闭电脑服务再恢复，应用显示断线/重试；过期旧请求不可复活。
- 同一按钮重复点击只报告已有结果，相反决定被拒绝。
- 停止/重启电脑服务，旧待处理请求取消。重新配对可直接在电脑控制窗点“重新配对，生成新码”；旧手机权限撤销。手机提示配对失效后重新输入配对码。
- 锁屏十分钟、系统省电模式与手机重启后分别验收。界面在线状态、通知显示、按钮回传三项分别记录。

安装验收由用户操作，本次没有通过 ADB 自动安装或修改用户手机设置。设备为“通用”不会跳过真实通知验收。

## 源码与构建

原生源码在 android/src，包括一个聊天原生视图、一个 Activity、一个 Service、一个内部 Receiver、HTTPS 请求与 URL 校验，以及复用的原生样式和文本排版辅助类。直接使用官方 javac/aapt2/D8/zipalign/apksigner，无 Gradle、UI 框架或应用运行库。

```powershell
powershell -ExecutionPolicy Bypass -File android\build.ps1
```

构建工具默认从工作区 `.android-tools` 查找；其他电脑可传 `-JdkPath`、`-BuildToolsPath`、`-PlatformJar` 指向官方 JDK 21、Android Build Tools 36、Android API 36 的 android.jar。生成 `dist\agent-bridge.apk`。工具下载仅是开发依赖，不打入 APK。构建脚本检查每一步退出码，并执行 Java URL 10 项、Markdown 16 项自测、签名和 ZIP 对齐验证。

签名私钥与随机密码在 `.android-tools\signing`，不包含在源码/交付 ZIP。请在电脑私下保管，后续同包名覆盖更新需要相同签名。卸载应用会删除手机配对凭证；换签名不能直接覆盖更新。不要把密钥、密码或 data 分享到聊天。

服务自测：`node tools/run-tests.mjs`。真实桌面消息联调及异步问题回传已通过；用户确认上一版手机桥功能可用。本次 UI 的真机体验需覆盖安装后确认，编译和文本解析测试不代替手机验收。

官方依据：
- 前台服务及 specialUse：https://developer.android.com/about/versions/14/changes/fgs-types-required
- 省电模式对网络的限制：https://developer.android.com/training/monitoring-device-state/doze-standby
- APK 签名验证：https://developer.android.com/tools/apksigner

## 停用与卸载

手机在“设置”页关闭“后台连接”或常驻通知的“停止连接”。电脑终端 Ctrl+C 停止服务；登录计划任务需另行停止/卸载。卸载 APK 后，电脑应重新配对以撤销旧手机凭证。真实 Codex 配置与原 notify 未改，无需恢复。
